## 2026-10-01 - Focus Management in Canvas Overlays
**Learning:** For WebGL/Canvas games with HTML overlays (like game over screens), focus isn't naturally directed to the overlay when it appears because the canvas often retains focus. This breaks keyboard navigation for users relying on the overlay. Adding `role="alert"` and `aria-live="assertive"` ensures screen readers announce the overlay, but manual focus management (`element.focus()`) must be explicitly triggered in the game loop when the state changes to ensure keyboard users can interact with the overlay actions.
**Action:** Always pair `role="alert"` on sudden modals with an explicit `.focus()` call on the primary action button (e.g., 'Try Again') and ensure custom focus outlines (`focus-visible`) are defined, especially in non-standard document flows like game engines.
